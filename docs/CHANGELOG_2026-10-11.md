# 2026-10-11 改动说明

本次更新包含当前工作区的行情观测、登录恢复、错误诊断改进，以及此前的交易记录与界面精简。

## 行情观测与请求处理

- 调整 Steam 历史接口请求头，保留 HTTP 状态和 JWT 刷新重定向信息，区分行情接口 429 与登录刷新接口 429。
- 历史请求使用账号池和代理切换；账号限流或鉴权失败时按现有策略处理，代理重试排除已经尝试的节点。
- 历史成交数据按商品、应用和成交时间写入 SQLite，保留原始价格、来源币种及人民币价格，合并重复时间点并复用缓存。
- 修复历史接口只返回 `¥` 时的币种缺失问题。根据请求账号已验证的钱包币种区分人民币和日元；身份不匹配或钱包校验失败时不猜测币种。
- 稳定性分析使用成交量统计有效交易数；普通选品提前检查折扣，减少无效历史请求。
- 仅观测模式读取历史成交、卖单并记录参考价；历史读取失败时跳过该候选的卖单请求。

## Steam Cookie 与登录

- 当前账号优先使用身份匹配的 Cookie，修复主凭据属于其他账号时的读取错误。
- 持久化 `cookie_refreshed_at`，独立后台任务每小时检查，在满七天、提前过期、缺失或身份不匹配时重新登录。
- 定期刷新在流水线和结账空闲时进行，不依赖 BUFF 保活开关；刷新非当前账号不会切换账号或覆盖当前凭据。
- 修复网络异常被误判为 Cookie 有效的问题；新 Cookie 的 Steam ID 与目标账号不符时拒绝保存。
- 登录等待 Steam 返回 refresh token，并为会话请求设置有界超时、按现有代理策略重试。
- 登录网络失败不进入账号冷却，后续刷新可以立即再次尝试；行情接口原有的限流和鉴权冷却仍然保留。

## 错误诊断与代理

- 错误包含请求 ID、模块、阶段、账号、商品、端点、代理、HTTP 状态、耗时和超时配置。
- 保留异常链、Windows 错误号及文件/行号/函数调用栈，区分连接重置、代理认证、TLS、超时、JSON 和数据库错误。
- 日志接口和导出保留结构化诊断；Cookie、JWT、密码、授权信息和代理凭据脱敏。
- BUFF 写请求失败保留“结果未知”的语义，不自动重复提交可能已经到达服务端的订单。
- 代理预热检查 Steam 可用性；检测完成后立即更新节点权重，失败节点立即停止参与选择。
- 从 CONNECT 异常链识别 HTTP 407，将其标记为 `PROXY_AUTH_REQUIRED`。

## 交易记录与界面精简

- 购买记录仅保存并显示确认付款的订单，持久化购买价格、参考价和折扣快照，兼容旧已付款记录。
- 精简库存、成交管理、下架、记录修复及持仓报告入口和相关后台逻辑；同步移除对应配置与测试。
- 调整首页、设置、账号和购买记录界面；未注册的 `/api/` 路径返回 404，避免误返回前端 HTML。
- 更新 README，补充诊断文档及相关回归测试。
